# EXPERTIMMOTC — site web

Site statique servi par GitHub Pages depuis la branche `main` (racine) sur https://expertimmotc.be.

- `index.html` : tout le site (HTML, CSS, JS, photo intégrée).
- `CNAME` : domaine personnalisé — ne pas supprimer.
- Pour mettre à jour : modifier `index.html`, commit, push sur `main`. En ligne en ~1 minute.

L'ancienne version React/Vite est conservée sur la branche `legacy-react`.
